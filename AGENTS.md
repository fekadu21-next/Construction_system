# Project Guidelines & Rules

## Temporary & Test Scripts
- **DO NOT create test files or scratch scripts (`test*`, `test_*.js`, etc.) inside the project directory** (e.g., inside `Backend/`, `Frontend/`, or `scratch/`).
- If any temporary diagnostic or verification script is required during development, run it in memory or store it strictly in the external agent artifacts directory (`<appDataDir>/brain/<conversation-id>/scratch/`).
- Never leave scratch or test files committed or remaining in the workspace.
